Руководство по установке и эксплуатации

------------------------------------------------------------------------

1. Назначение программы

Программный комплекс предназначен для управления станком намотки статора,
реализованным на базе 3D-принтера, либо для его имитации в среде CoppeliaSim.
Пользователь может выбрать один из двух режимов: работа с реальным станком
или тестирование и отладка в виртуальной среде.

Система позволяет: 
- Загружать управляющие программы в формате G-кода.
- Преобразовывать G-код в команды симуляции.
- Тестировать процессы намотки в виртуальной среде.
- Управлять станком посредством контроллера.

------------------------------------------------------------------------

2. Состав поставки

В состав программного комплекса входит:
- Архив проекта python_control.zip, содержащий:
- Папку modules/ с исходными модулями на Python.
- Jupyter Notebook-файлы (.ipynb) для тестов и интерфейсов.
- Библиотеки взаимодействия с CoppeliaSim (remoteApi.dll, sim.py,
simConst.py).
- Вспомогательные текстовые файлы.

------------------------------------------------------------------------

3. Требования к средствам эксплуатации

-   Anaconda (Python 3.12).
-   CoppeliaSim последней стабильной версии.
-   Установленные библиотеки:
    -   numpy, matplotlib, jupyter, tkinter.
-   Драйверы USB (если используется физическое подключение станка).

------------------------------------------------------------------------

4. Инструкция по установке

1.  Установить Anaconda с официального сайта:
    https://www.anaconda.com/download.

2.  Установить CoppeliaSim с сайта
    https://www.coppeliarobotics.com/downloads.

3.  Распаковать архив python_control.zip в каталог
    C:\Projects\python_control.

4.  Создать окружение Anaconda:

        conda create -n python_control_env python=3.12
        conda activate python_control_env

5.  Установить необходимые библиотеки:

        conda install numpy matplotlib jupyter tk

------------------------------------------------------------------------

5. Инструкция по запуску

1.  Запустить CoppeliaSim.

2.  Открыть сцену станка (файл формата .ttt).

3.  В Anaconda Prompt перейти в каталог проекта:

        cd C:\Projects\python_control

4.  Для запуска ноутбуков:

        jupyter notebook

    -   G-code_to_coppelia.ipynb - загрузка и преобразование G-кода.
    -   Tk_draft*.ipynb - интерфейсные наработки.

------------------------------------------------------------------------

6. Структура проекта

-   Основные модули:
    -   ClientCoppeliaSim_01.py - подключение к CoppeliaSim.
    -   CoppeliaController_01.py - упрощенное управление объектами симуляции.
    -   PrinterController_01.py - прикладной коммуникационный слой между пользовательским интерфейсом и управляющей электроникой 3D-принтера/станка.
    -   GcodeArea_01.py - парсинг и обработка G-кода.
    -   CordsEnterArea_01.py - ввод координат вручную.
    -   Array_controll_01.py - библиотека вектроных преобразований между системами координат.
-   Jupyter Notebook:
    -   G-code_to_coppelia.ipynb - загрузка G-кода и интеграция с
        симуляцией.
    -   Tk_draft*.ipynb - тестовые интерфейсы на Tkinter.
    -   draft_1.ipynb - экспериментальные сценарии.
-   Служебные файлы:
    -   remoteApi.dll, sim.py, simConst.py — библиотека API для
        взаимодействия с CoppeliaSim.
    -   untitled.txt - временные/черновые файлы.

------------------------------------------------------------------------

7. Условия эксплуатации

-   Программный комплекс предназначен для использования обученными
    пользователями.
-   Работа может вестись как с включённой симуляционной средой, так и
    напрямую с реальным станком - запуск возможен и без запущенной
    CoppeliaSim.
-   При модификации кода рекомендуется использовать отдельное окружение
    Anaconda.

------------------------------------------------------------------------
